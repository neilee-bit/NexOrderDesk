## NEX ORDER DESK 2.8.0

### Fixed
- **Coordinator now always appears on the submitted order, print and PDF.** Drawing the sheet for Submit / Print / PDF used to erase the selected coordinator. The name is now kept on the order, shown on the submitted sheet and still selected when you press Edit.

### New
- **Print and PDF only for submitted orders.** While an order is being created or edited the Print and PDF buttons are hidden (also Ctrl+P); they appear as soon as you press Submit. Works the same on every order type (T-shirt, Jacket, Bottoms, Flags, DTF).
- **Garment category and sleeve type in the size table.** The adult columns have two small drop-downs in their headers: category (Adults, Unisex, Gents, Lads) and sleeve (S/S, L/S) - for example "Gents (L/S)". Each column is set independently, the sizes are tagged with the chosen sleeve, and the choice is printed on the sheet and in the PDF.
- **Empty size columns are left off the submitted sheet.** Columns without any quantity disappear from the submitted order, print and PDF; the remaining columns share the width so there are no empty gaps. On Bottoms / Shorts the filled sizes sit right next to the total. Quantities and totals are never changed, and Edit brings every column back.
- **Customer suggestions.** Click the Customer field or start typing to see matching customers (29 customers included, partial match, keyboard Up/Down + Enter or mouse click). Any new name can still be typed - it is suggested automatically next time. "+ Add / edit customer list…" at the bottom of the suggestions edits the list.

### Notes
- Your settings, option lists, order types and saved PDFs are kept when you update.
