## NEX ORDER DESK 2.7.0

### New
- **Online updates.** "Check for updates" in the top bar checks GitHub for a newer version. NEX ORDER DESK can also check by itself when it starts (you can switch this off).
- Updates download with a progress bar, are checked with a SHA256 security checksum, and install with the normal Windows installer. The app restarts by itself afterwards.
- The version number shown in the app, the installer and the update information now always match.

### Notes
- Your settings, option lists, order types, icons and saved PDFs are kept when you update.
- Without internet NEX ORDER DESK works exactly as before.
