## NEX ORDER DESK 2.9.0

### Fixed
- **Dark theme colours:** the order number, totals, print method and every other text on the theme colour now switch to white on dark themes (navy, black, purple…) and stay dark on light themes - always readable, on screen, in print and PDF.

### Improved
- **Customer suggestions:** slim, smooth scroll bar.
- **Bold selections:** chosen values such as Neck Type "Full Collar", sleeve, placket, material and coordinator are shown in bold.
- **Pictures:** a single uploaded picture now fills its image area (front / back cards and the Flags / DTF workspace).
- **Long order names** (and customer names) shrink to fit their box instead of being cut off.
- **Submit:** the saved copy's location is no longer shown after submitting.

### New
- **Material colour by name:** type a colour (navy blue, bottle green, ash melange, light pink, maroon …) and the colour is found automatically - suggestions with swatches appear while typing, small typing mistakes are understood. No colour codes any more (also in the colour list editor).
- **Print and Press sheet:** Neck Type, Collar Color, Sleeve Type, Placket Type & Color and Button rows removed. New **Collar Patch** and **Placket** rows with a tick box and colour - they appear on the submitted sheet only when ticked. Piping stays.
- **Bottoms / Shorts sizes:** the full adult range 4XS to 5XL, plus **+ Kids** (K3XS-K3XL) and **+ PS** (P4XS-PXL) size lines; other sizes still available.
- **18 more apparel icons** for order types: cap, frock, skirt, polo, long sleeve, shirt, hoodie, sweater, tank top, vest, sports jersey, trousers, baby romper, hat, socks, apron, bag, scarf.
- **Ctrl+N** opens a new order (choose the type); **Ctrl+Shift+N** opens a new order of the same type as the current one.

### Notes
- Settings, option lists, customers, order types and saved PDFs are kept when you update.
